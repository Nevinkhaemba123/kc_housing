## 📌 Project Overview
This repository contains an end-to-end data science and econometric modeling pipeline built on the **King County House Sales dataset**. The primary objective is to analyze key housing market drivers, engineer informative spatial and structural features, and develop high-performing regression models to accurately predict residential property prices.
